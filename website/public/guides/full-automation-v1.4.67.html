2026-06-05 · 적용 버전 v1.4.67 (프로그램을 최신으로 업데이트하면 자동 적용됩니다)

1풀 자동화 준비 상태 카드

‘풀 자동화 소싱’ 화면을 열면 맨 위에 준비 상태 카드가 나타납니다. 영상 제작·발행·업로드를 자동으로 돌리는 데 필요한 4가지(① AI 분석 ② YouTube 연결 ③ Linktree 발행 ④ 쿠팡 딥링크)가 준비됐는지 한눈에 보여줍니다.

준비 완료 설정이 필요해요 선택 항목
  • 한눈에 확인 — 무엇이 준비됐고 무엇이 빠졌는지 색으로 바로 알 수 있어요.
  • 한 번에 이동 — 빨간 항목의 설정하기를 누르면 그 자리에서 설정 화면이 열립니다.
  • 옵션 연동 — ‘YouTube 자동 업로드’·‘링크트리 자동 발행’ 체크를 끄면 해당 항목은 ‘사용 안 함’으로 표시되어 신경 쓸 필요가 없어요.

2YouTube, 빠진 줄 모르고 지나가는 일 없게

예전에는 ‘YouTube 자동 업로드’를 켜도 채널이 연결되지 않았으면 조용히 업로드가 건너뛰어지는 경우가 있었어요. 이제는 소싱을 시작하기 전에 연결·계정 확인이 안 됐다면 분명하게 알려드립니다. 안내에 따라 연결만 해주면 끝!

💡 채널 연결은 업로드 설정 탭에서 OAuth JSON 파일만 올리면 됩니다. 준비 상태 카드의 ‘설정하기’가 바로 그 화면으로 데려다줍니다.

3Linktree 자동 발행 — 간편 설정 가이드

Linktree에는 공식 ‘자동 등록’ 기능이 없어, 웹훅(Webhook)이라는 중계 주소를 한 번 연결해 두면 쿠팡 카드가 자동으로 올라갑니다. 어렵게 느껴졌던 이 과정을 3단계 가이드로 정리했어요.

  1. 내 Linktree 공개 주소 입력 — 예) https://linktr.ee/myshop
  2. 웹훅 연결 — Make·Zapier·n8n 등에서 ‘Webhook’ 주소를 만들어 붙여넣습니다. 화면의 예시 데이터 복사로 어떤 값이 오는지 그대로 확인할 수 있어요.
  3. 테스트하고 켜기 — 테스트 발행으로 연결을 확인한 뒤 저장하고 닫기를 누르면 자동 발행이 켜집니다.

여는 방법: 준비 상태 카드의 Linktree 설정하기, 또는 설정 ▸ Coupang/Linktree 자동화 ▸ 🪄 간편 설정 가이드.

이렇게 쓰시면 됩니다

  1. 프로그램을 v1.4.67로 업데이트합니다.
  2. 첫 화면에서 풀 자동화 소싱을 선택합니다.
  3. 맨 위 준비 상태 카드에서 빨간 항목이 있으면 설정하기로 연결합니다.
  4. 모두 초록(✓)이 되면 쿠팡 링크를 넣고 소싱 시작 — 끝!

Q. 웹훅이 꼭 필요한가요?

Linktree 자동 발행을 쓸 때만 필요합니다. ‘링크트리 자동 발행’ 체크를 꺼두면 웹훅 없이도 영상 제작·YouTube 업로드는 그대로 사용할 수 있어요.

Q. 쿠팡 파트너스 키가 없어도 되나요?

네. 키가 없으면 원본 쿠팡 링크로 발행됩니다(딥링크 자동 변환만 생략). 그래서 준비 카드에서 ‘선택’ 항목(주황)으로 표시돼요.

언제나 더 쉽고 편안하게. 궁금한 점은 고객센터로 문의해 주세요. 🙌
