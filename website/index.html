SSMaker - 쇼핑 숏폼 자동 변환 AI 솔루션

SSMaker는 중국 쇼핑 영상을 한국어 숏폼 콘텐츠로 변환하고 쿠팡 파트너스 단축 링크, YouTube Shorts, Linktree 운영 흐름을 연결하는 Windows 프로그램입니다.

주요 기능

  • OCR 기반 중국어 자막 위치·노출 시간 감지와 블러
  • 상품 정보 기반 한국어 세일즈 스크립트와 TTS 음성 생성
  • 세로형 쇼핑 영상 렌더와 병렬 일괄 처리
  • YouTube Shorts 업로드 및 Linktree 상품 링크 검수 지원

요금제

무료 체험은 0원이며 프로 월 정액은 월 149,000원입니다.
